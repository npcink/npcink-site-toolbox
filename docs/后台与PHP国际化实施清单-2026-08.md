## 状态定义

- **已覆盖**：文案经过 WordPress 翻译函数或后台 `wp-i18n` helper，且关键 `msgid` 已进入 POT 并有运行时测试。
- **待实施**：用户可见，但当前仍是硬编码、动态字符串未提取，或缺少运行时/契约验证。
- **保留原文**：用户输入、机器 ID、审计分类、数据库键、第三方品牌名等不应被翻译；如在界面显示，必须在显示层决定是否翻译。
- **待决策**：同一数据既用于 UI 又用于 AI/审计协议，需要先确定显示语言和稳定协议边界。

## 不应直接翻译的内容

- 用户在设置中填写的标题、正文、维护提示和自定义 CDN 规则；
