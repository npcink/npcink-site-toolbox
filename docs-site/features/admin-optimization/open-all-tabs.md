# 批量打开编辑和查看

## 功能说明

在文章、页面和已注册后台列表的自定义文章类型中，按当前筛选和分页结果批量打开行操作链接。编辑页和查看页可以分别开启；WordPress 没有为当前用户输出的链接不会被打开。

## 开启方法

1. 进入 **Npcink Site Toolbox** → **站点与媒体** → **后台**。
2. 开启「在新标签页打开全部编辑」或「在新标签页打开全部查看」，也可以同时开启。
3. 保存配置，然后进入任意文章类型的后台列表页。
4. 点击顶部工具栏中对应的按钮。

按钮只处理当前页的结果。查看按钮使用原生「查看」链接，不打开草稿的「预览」链接。浏览器如果拦截了批量弹出窗口，请允许本站弹出式窗口后重新点击。

## 自定义文章类型要求

自定义文章类型需要注册后台列表（`show_ui`）并为当前用户提供编辑或查看权限。不可编辑的行不会出现在编辑按钮的链接集合中；未公开或没有前台查看地址的文章类型可能没有查看按钮可打开。
