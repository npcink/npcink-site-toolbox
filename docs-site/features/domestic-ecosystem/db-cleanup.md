# 数据库清理

::: warning 高风险维护
仅在确认数据类型、影响数量并完成数据库备份后执行。不要把清理当作日常提速按钮。
:::

## 功能说明

清理 WordPress 数据库中的垃圾数据，包括修订版本、草稿、垃圾评论、临时数据等，减少数据库体积，提升查询性能。

## 可清理的数据类型

| 类型 | 说明 | 影响 |
|------|------|------|
| 修订版本 | 文章历史修订记录 | 删除后无法恢复历史版本 |
| 自动草稿 | `auto-draft` 状态的内容 | 删除后无法恢复 |
| 垃圾评论 | 标记为 spam 的评论 | 删除后无法恢复 |
| 过期临时选项 | 已超过超时时间的 Transient | 需要时由对应代码重新生成 |
| 待审核文章 | `pending` 状态的文章 | 永久删除，谨慎操作 |
| 回收站文章 | `trash` 状态的文章 | 永久删除 |
| 数据库表优化 | 优化当前站点前缀下的安全表名 | 不删除内容，但仍建议先备份 |

## 使用场景

- 数据库体积过大，查询变慢
- 修订版本积累过多
- 大量垃圾评论占用空间
- 定期维护数据库

## 开启方法

1. 进入 **插件** → **Npcink Site Toolbox** → **存储与维护** → **数据库清理**
2. 开启「数据库清理」
3. 点击「查看统计」
4. 对需要处理的单个项目点击「预览」
5. 核对中文项目名、预计影响数量和数据库备份
6. 在 5 分钟内点击「清理」并再次确认

预览资格只绑定当前管理员和当前清理项目，只能使用一次。执行前服务端会重新计算相同项目；如果数量或数据库表集合发生变化，会拒绝清理并要求重新预览。刷新页面、预览过期或重复提交同一个预览资格时，也必须重新预览。

## 配置选项

| 选项 | 说明 | 推荐 |
|------|------|------|
| 清理修订版本 | 删除文章历史修订 | ✅ |
| 清理草稿 | 删除自动草稿 | ✅ |
| 清理垃圾评论 | 删除 spam 评论 | ✅ |
| 清理临时数据 | 删除过期 transient | ✅ |
| 自动清理 | 定时自动清理 | - |
| 清理周期 | 自动清理频率 | 每周 |

## 注意事项

- **清理前务必备份数据库**
- 修订版本删除后无法恢复
- 必须先查看预估清理数据量；没有有效预览时服务端不会执行
- 数据发生变化后必须重新预览，不会沿用旧数量继续删除
- 自动清理功能适合定期维护
- 清理操作不可逆，请谨慎操作

## 性能影响

实际收益取决于站点数据量、查询模式和数据库环境，不能用固定百分比承诺。清理后应以数据库体积、慢查询和页面响应时间的实际变化判断效果。
