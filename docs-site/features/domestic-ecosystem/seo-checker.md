# SEO 检查助手

::: tip 推荐
SEO 建议开启。
:::

## 功能说明

检查站点 SEO 健康度，发现缺失的 TDK、图片 Alt 等问题。图片 Alt 只做缺失检测，不自动写入，避免与站点已有 SEO 或媒体插件冲突。

## 检查项

- 首页标题和描述是否为空
- 文章是否缺少 SEO 标题和描述
- 分类是否缺少描述
- 标签是否过多
- 文章是否没有特色图
- 图片是否缺少 Alt

### 图片 Alt 处理边界

本模块只报告缺少 Alt 的图片数量和检查结果，不提供自动写入入口。请使用站点已经启用的 SEO/媒体插件或 WordPress 媒体库逐张确认并填写，避免多个插件对同一个 `_wp_attachment_image_alt` 字段产生冲突。

## 开启方法

1. 进入 **魔法工具箱** → **国内生态**
2. 开启「SEO 检查助手」
3. 保存配置
