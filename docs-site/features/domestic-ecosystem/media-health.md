# 媒体库体检

::: tip 推荐
建议开启。
:::

## 功能说明

检查媒体库中的问题，包括缺少 Alt 的图片、超大图片、中文文件名图片和未使用图片。Alt 只做缺失检测，不自动写入，避免与站点已有 SEO 或媒体插件冲突。

## 检查项

- 缺少 Alt 的图片
- 超大图片（如超过 500KB）
- 中文文件名图片
- 未使用图片
- 无特色图文章

Alt 处理请使用站点已有的 SEO/媒体插件或 WordPress 媒体库人工完成。本模块不会写入 Alt，也不会覆盖其他插件或人工填写的值。

## 开启方法

1. 进入 **魔法工具箱** → **国内生态**
2. 开启「媒体库体检」
3. 保存配置
